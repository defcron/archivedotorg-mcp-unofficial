# Wayback feature coverage

This is a v0.1.0 preview, not a claim that all Internet Archive functionality can be exposed through public APIs.

| Feature                                                 | Status                                      | Interface and caveat                                                                                                                                                      |
| ------------------------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Closest/latest capture                                  | Implemented                                 | Official Availability API; returned date can differ                                                                                                                       |
| Capture history, dates, MIME/status filters             | Implemented                                 | Official CDX API                                                                                                                                                          |
| Host/domain/path inventory                              | Implemented                                 | CDX match types and urlkey collapsing; not keyword/full-text search                                                                                                       |
| Pagination and adjacent duplicate suppression           | Implemented                                 | CDX resume keys; preserve query between pages                                                                                                                             |
| Calendar and timeline                                   | Implemented, best-effort                    | Website-internal calendarcaptures/sparkline APIs                                                                                                                          |
| Replay / raw page / link extraction                     | Implemented                                 | Archive-only redirects; no JS execution                                                                                                                                   |
| Binary archived objects                                 | Link provided                               | No binary blobs inserted into LLM context                                                                                                                                 |
| Changes                                                 | Implemented                                 | CDX digest candidates plus extracted-text comparison                                                                                                                      |
| Visual comparison                                       | Website link                                | Pixel rendering and the older simhash service are not recreated                                                                                                           |
| Memento discovery                                       | Implemented adapter                         | Bounded CDX-derived mementos and native Link-format timemap URL; not an independent TimeGate server                                                                       |
| Save Page Now                                           | Implemented, upstream permissions apply     | POST submission, single-job polling and outlink status                                                                                                                    |
| Save options                                            | Implemented                                 | Error pages, outlinks, screenshot, delayed visibility, force GET, first-capture check, recency reuse, outlink availability, JS behavior timeout, custom public user agent |
| Screenshot capture                                      | Option implemented                          | Screenshot creation occurs upstream; not a local browser screenshot renderer                                                                                              |
| Save service status                                     | Implemented                                 | Anonymous service health; account quota requires configured credentials                                                                                                   |
| Exact capture verification                              | Implemented                                 | CDX lookup; indexing can lag                                                                                                                                              |
| Target-site login, cookies and email reports            | Intentionally not exposed in public preview | Avoid secrets in model arguments and unexpected publication/messaging                                                                                                     |
| Authenticated Internet Archive saves                    | Code available, not enabled publicly        | Requires a protected private deployment and IA S3 keys                                                                                                                    |
| Google Sheets/bulk spreadsheet capture workflows        | Not implemented                             | Website workflow; bounded per-page submissions are available                                                                                                              |
| User collections, favorites, account settings           | Not implemented                             | Requires an authenticated product integration                                                                                                                             |
| Exclusion, takedown and archive deletion                | Not automated                               | Follow Internet Archive's own processes                                                                                                                                   |
| Full-text keyword search across the web archive         | Not implemented                             | No general supported API is asserted                                                                                                                                      |
| Archive.org books, media, item upload/download, lending | Future phase                                | This release is Wayback-first                                                                                                                                             |

Public endpoint errors are returned as MCP `isError` results with a code, HTTP status where available, and Retry-After hints. Missing archives, failures and access denials are not silently replaced with invented data.
